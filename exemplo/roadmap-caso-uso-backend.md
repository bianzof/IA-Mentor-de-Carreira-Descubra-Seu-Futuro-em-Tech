### 🕒 1. VISÃO DO DIA A DIA
Um desenvolvedor backend trabalha nos bastidores dos sistemas, garantindo que a lógica funcione, que os dados sejam processados corretamente e que o sistema seja seguro e escalável. O dia a dia envolve:  
- Escrever e revisar código em linguagens como Java, Python ou Node.js.  
- Criar e manter APIs que conectam o frontend ao backend.  
- Trabalhar com bancos de dados relacionais e não relacionais.  
- Resolver bugs e otimizar performance.  
- Colaborar com equipes de frontend e QA, mas com bastante tempo de *deep work*.

💬 **ROTEIRO DE ENTREVISTAS**  
**PERGUNTA 1:** O que é uma API REST?  
**COMO RESPONDER:** Explique que é um conjunto de rotas que permitem comunicação entre sistemas usando métodos HTTP (GET, POST, PUT, DELETE).  

**PERGUNTA 2:** Qual a diferença entre SQL e NoSQL?  
**COMO RESPONDER:** SQL usa tabelas relacionais, NoSQL é mais flexível e trabalha com documentos ou chave-valor.  

**PERGUNTA 3:** Como funciona a autenticação JWT?  
**COMO RESPONDER:** O servidor gera um token assinado que o cliente usa para acessar recursos protegidos.  

**PERGUNTA 4:** O que é um middleware no Express?  
**COMO RESPONDER:** É uma função que intercepta requisições e pode modificar ou validar antes de chegar à rota final.  

**PERGUNTA 5:** Como você garantiria a segurança de uma API?  
**COMO RESPONDER:** Usando validação de inputs, autenticação, criptografia de senhas e boas práticas de configuração.
